# Lenya — заявки для водителей

Простое веб-приложение для менеджера транспортной компании: создание заявок для водителей, добавление водителей, доска с активными заявками.

## Запуск

Нужен только Node.js 22 или новее — никаких зависимостей ставить не нужно.

```bash
node server.js
```

Откройте в браузере: http://localhost:3000

## Что внутри

- **База данных** — SQLite (встроенный модуль Node.js), файл `lenya.db` создаётся автоматически при первом запуске рядом с `server.js`.
- **Сервер** — `server.js`, чистый Node.js без фреймворков, отдаёт статику и REST API.
- **Интерфейс** — `public/` (HTML/CSS/JS без сборки):
  - Главная — выбор действия (создать заявку / добавить водителя / доска)
  - Создание заявки — пошаговый мастер: водитель → детали рейса → подтверждение. На первом шаге можно выбрать существующего водителя или сразу завести нового.
  - Добавление водителя — пошаговый мастер: данные → транспорт → подтверждение
  - Доска — карточки водителей с их заявками, смена статуса прямо на карточке
  - Водители — список с удалением

## API (если пригодится)

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/drivers` | Список водителей (+ число активных заявок) |
| POST | `/api/drivers` | Добавить водителя |
| PUT | `/api/drivers/:id` | Изменить водителя |
| DELETE | `/api/drivers/:id` | Удалить водителя (если нет заявок) |
| GET | `/api/orders` | Список заявок |
| POST | `/api/orders` | Создать заявку |
| PATCH | `/api/orders/:id/status` | Сменить статус (`new`, `in_progress`, `done`, `cancelled`) |
| DELETE | `/api/orders/:id` | Удалить заявку |

## Настройки

Через переменные окружения:

- `PORT` — порт сервера (по умолчанию 3000)
- `DB_PATH` — путь к файлу базы данных (по умолчанию `./lenya.db`)
